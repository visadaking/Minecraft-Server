# github release - windows

Contents: the Minecraft server stack for Windows (PowerShell 5.1, `start.bat`
launcher, hidden helpers, panel, Discord feed/chat bridge, backups, TPS
monitor, auto-update).

Place finished release ZIP files here too, e.g. `minecraft-stack-2026-10-28.zip`.

Install: copy everything next to `server.jar` (Mojang download), open
`start.bat`, and open the panel at http://10.0.0.15:8787 (LAN only, never
localhost). Fill your Discord webhook/bot into `discord\` yourself - tokens are
not shipped.
